## 2. Implementation: `common/states.py`

- `AgentCaseState`, `DispatchState`, `PortalBatchState`: `StrEnum` classes with
  explicit upper-case values, e.g. `SCORING = "SCORING"`. Don't use `auto()`:
  it gives lower-case values.
- One table per machine. It is the only place where moves are defined (rule 6):
  `AGENT_CASE_MOVES`, `DISPATCH_MOVES`, `PORTAL_BATCH_MOVES`. Each is a
  `Mapping[State, frozenset[State]]` wrapped in `types.MappingProxyType` so it
  is read-only. The moves are written out in full, including CANCELLED in every
  non-final agent entry, so the owner can check them line by line against the
  spec. Final statuses map to an empty frozenset.
- `class InvalidTransition(ValueError)` with `current` and `proposed`
  attributes and the message `"Cannot move {label} from {current} to {proposed}"`.
- A private registry maps each enum to its label and table, e.g.
  `{AgentCaseState: ("agent case", AGENT_CASE_MOVES), ...}`.
- A constrained `S = TypeVar("S", AgentCaseState, DispatchState, PortalBatchState)`
  makes mypy reject calls that mix machines. As a runtime backstop,
  `type(current) is type(proposed)` is checked and a mismatch raises `TypeError`.
- Public functions:
  - `allowed_moves(state: S) -> frozenset[S]`
  - `is_final(state) -> bool`: true when the state's move set is empty.
  - `can_transition(current: S, proposed: S) -> bool`. Same-status moves and
    moves out of a final status are refused by the tables themselves, because
    neither appears as an allowed target.
  - `require_transition(current: S, proposed: S) -> None`: raises `InvalidTransition`.
- `__all__` lists the public names. Small functions with full type hints.
